## 怎么复现（原文）

1. 装依赖、跑测试：`npm ci`；`npm test`；`npm run build` 后 `npm run test:e2e`（用本机 Edge；系统设了代理时先设 `NO_PROXY=127.0.0.1,localhost`）。不需要任何密钥。
2. 重算实验报告、不花钱：拿到原始数据目录后，`npm run experiments -- --from <目录>` 用已跑完的数据按当前口径重算报告，不调用模型；`npm run eval:summarize -- --input <目录>` 重算汇总并核对分母。
3. 重跑实验：在 `.env.local` 填模型密钥，`npm run experiments -- --suite <套件>` 先只打印计划和粗估的调用次数，确认后加 `--yes` 才真跑。真实模型的输出每次会有差别。
