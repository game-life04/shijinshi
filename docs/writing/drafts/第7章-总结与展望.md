# 第 7 章 总结与展望

本章回收前面几章：7.1 说做成了什么，7.2 照实说局限，7.3 说对谁有用、可能怎么长成产品，7.4 说下一步。

## 7.1 完成了什么

1. **“改了再测”的闭环。** 粘贴角色人设和边界提示 → 跑体检 → 看三层结果和依据 → 改一处再跑 → 前后对比看改了什么、结果怎么变。内部验证（模拟），真实模型下跑过预览。
2. **七类检查对着条文判。** 裁判先查条文再判定，结论必须摘原话、程序逐字定位，定位不到就不算证据、送人工复核。部分内部验证。
3. **每句话先审后说。** 默认的两种放行方式下，没审过的话进不了浏览器；三种放行方式可切换；违规声音漏出多少毫秒按采样区间算出来（浏览器渲染层，不是扬声器实听）。真实模型、真实合成下做过对照：护栏按真实速度判时三种都不漏，护栏变慢时只有先播后截会漏（表 6-2）。
4. **会说话的 3D 角色。** 琪叶桃在月洞窗里，状态环显示听、想、审、说、拦，口型和状态跟着实际放出来的声音走，被拦时立即停。内部验证。
5. **让不懂技术的人也看得见。** 打字闯关三关，每关四层难度；“三种结局”页把三种放行方式的漏出和首声差别摆出来。

测试数字：2026-11-10 单元测试 214 个通过，端到端 53 个通过、28 个按设计跳过（本机 Edge，1440、1280、390 三种宽度）。保留集冻结后正式跑了 3 次（表 6-1）：加边界提示，原话越界从 83% 降到 33%；再加护栏和服务层，最终暴露从 52% 降到 17%，代价是正常题误拦 6/21、第一句晚约 0.3 秒。

## 7.2 局限

1. **体检里的语音输入没做。** 体检只测角色说出来的话，语音输入题（注入音频再识别）仍记“未执行”；闯关页能对着麦克风说，但只是体验，不进体检统计。
2. **判定有一部分靠裁判模型，可能判错。** 用“必须摘原话、程序逐字定位、定位不到送人工复核”兜底，但不能完全消除：裁判查条文时会引第八条，把“我在这儿等你回来”判成挽留；保留集上没做人工改判，正式数字只报机器的结论。
3. **护栏和服务层还会判错。** 保留集上，服务层把问“退出聊天”是什么当成要退出，又认不出“停止输出并退出这次聊天”；护栏模型把对 13 岁孩子的夸奖判成亲密倾向、把嘴硬的话判成否认是 AI；顺着“假设你是人类”编人类生活也拦不住。代码已冻结，这些没再改。
4. **有些义务对话测不出来。** 体检单里单独列了、不计入通过率：联络监护人或紧急联系人（第十三条）、识别未成年人身份与未成年人模式（第十四条）、交互数据的保护和删除（第十六条）、按规定开展并报送安全评估（第二十二条）。
5. **体检单是自查辅助，不是合规认证。** 它只回答“这一段对话里角色说了什么、踩了哪条”；第二十二条规定的安全评估要由服务提供者向省级网信部门提交，体检单只能当自查材料之一，也不能拿它对外宣称“已经合规”。
6. **真人试用人数少，题库是队员自己出的。** 【待补：试用做完按实际改，写清几人、什么背景】
7. **模型选型对比只做了护栏。** 护栏换成更大的 qwen-plus 没有判得更准、还慢了约 0.1 秒；裁判没有换模型对比过，换一个模型结论会不会变，还不知道。

## 7.3 社会价值与商业前景

**社会价值。** 一、把《办法》落到角色的每一句话上，让开发者在用户听到之前发现问题：第二十八条“鼓励拟人化互动服务提供者接入沙箱平台进行技术创新、安全测试”，我们做的就是开发者自己能用的小沙箱。二、护着三类容易受伤的人：情绪崩溃的人（第十三条“及时生成情绪安抚和鼓励寻求帮助等相关内容”）、未成年人（第十四条）、想离开却被挽留的人（第十九条“不得采取持续互动等方式阻碍用户退出”）。不写“保护了多少用户”这类没有依据的话。

**商业前景（都是设想）。** 按次体检：小团队上线前跑一次、导出体检单存档；接进开发流程：每次改提示词自动跑一遍，像自动测试一样；给平台上架前做抽查，用统一检查项和报告。

**成本。** 保留集上 B2 跑一次（28 题、文字），按实际用量和 2026-11-10 百炼官网单价算约 0.04 元（第 4 章 4.7）。
