## 怎么用 Codex 写

1. 拿到仓库：队长在 GitHub 上把你加为私有仓库 `game-life04/shijinshi` 的协作者，你用自己的账号克隆下来；拿不到的话请队长把仓库打包发你。
2. 用 Codex 打开仓库根目录。Codex 会先读根目录的 `AGENTS.md`，里面写了写文档的规矩。
3. 每章模板最后都有一段「给 Codex 的话」，复制过去就行。Codex 只起草，草稿写到 `docs/writing/drafts/` 下面，不改代码，不改别的文档。
4. 草稿出来以后，你逐段核对：
   - 每个事实点开出处看一眼，对不上就删；
   - 每段改成你自己的话（不要原样交 Codex 写的）；
   - 拿不准的地方标【待确认】，留给队长看。
5. 改好的稿子交给队长，他统一排版、加封面和目录，印成 PDF。

## 写作规矩（这几条最要紧）

1. **只写查得到的。**
   - 每个功能、数字、条文都要能指到仓库里的文件，或者一个你亲自打开过的网页。
   - 草稿里在句子后面用注释写出处，比如 `<!-- 出处：docs/pilot-log.md 第 1 轮 -->`，排版时队长会删掉。
2. **数字有讲究。**
   - 模拟数据、草稿题跑出来的数，不能当实验结果写。比如 `docs/pilot-log.md` 里的拦截次数，只能说成「调试中发现的问题」。
   - 正式实验的数字还没出来，先写【待补：哪个实验、哪个数】，不要估一个填上。
3. **不编调查和文献。**
   - 要引用别人的调查、新闻、论文，必须是你自己找到、打开、读过的，记下网址、发布单位、日期。
   - Codex 给的「某机构调查显示……」一律删掉重查。
4. **条文照原文。**
   - 法规全文在 `kb/clauses.jsonl`。引用时写第几条、原话加引号，不要凭印象改写。
   - 第一次出现写全称《人工智能拟人化互动服务管理暂行办法》，后面写《办法》。
5. **不能出现的内容：**
   - 任何真人姓名：队员写「队员 A」「队员 B」，提交前队长统一改；
   - 实习单位、公司、医院、病人相关的任何信息；
   - 密钥、账号和密码、服务器地址、内网地址；
   - 画师的名字（主视觉对外只说「墨色赛璐璐加镜头色散」），别家游戏或动画里的角色名。
6. **体例：**
   - 小标题按「1.1」「1.2」编号；
   - 每章开头一两句话说这一章讲什么；
   - 正文用「我们」；一段不超过五六行，能用表格就用表格。
7. **名字统一：**
   - 作品叫「分寸」，副标题「AI 语音角色安全体检台」，默认被测角色叫「琪叶桃」；
   - 其他名词照 `00-我们做了什么.md` 最后的名词表。
