**怎么复现。** 跑测试不要密钥：`npm ci`、`npm test`，`npm run build` 后 `npm run test:e2e`。重算报告不花钱：`npm run experiments -- --from <目录>`。重跑实验：`.env.local` 填密钥，`npm run experiments -- --suite <套件>` 先打印计划，加 `--yes` 才真跑。
