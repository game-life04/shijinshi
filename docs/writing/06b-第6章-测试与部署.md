| 指标 | 怎么算 | 看什么 |

## 6.4 部署方式

**本机运行（评委在自己电脑上试）。** 只需要 Node.js 22.12 以上（推荐 24），不填任何密钥也能跑：没有模型密钥时自动用确定性模拟器，界面上标「模拟」。<!-- 出处：README「快速开始」；package.json engines；ADR-002 -->

```bash
npm ci                         # 国内网络可加 --registry=https://registry.npmmirror.com
cp .env.example .env.local     # 不填 LLM_API_KEY 也能运行（模拟模式）
npm run dev                    # 打开 http://127.0.0.1:3000，首屏就是体检工作台
```

要接真实模型，在 `.env.local` 里填模型密钥（`LLM_API_KEY`），四个角色的模型名可以分别用环境变量换。看首声快慢要用生产构建：`npm run build` 后 `npm start`，开发模式自己的开销会让首声慢好几倍。两种方式都只在本机 127.0.0.1 监听。<!-- 出处：README「快速开始」；.env.example 变量名；ADR-020「以后首声数据只在 next build + next start 下量」；package.json scripts（-H 127.0.0.1） -->

**上线演示。** 放到公网上时，网站背后用的是队伍的模型密钥，所以必须先配账号：<!-- 出处：docs/deploy.md 开头 -->

| 步骤 | 做什么 |
|---|---|
| 1 | 服务器装好 Node.js 22.12 以上，能访问百炼接口；克隆仓库、`npm ci`，复制 `.env.local` 并设成只有自己能读 |
| 2 | `npx tsx scripts/account.ts secret` 生成会话密钥；`add <账号名>` 给每个要用的人生成一条账号记录（密码输两遍、不显示），写进 `.env.local`；`check` 检查配置，看到「账号登录已启用」才算对 |

## 6.5 隐私与密钥

| 要保护的 | 怎么做 |
|---|---|
| 模型密钥 | 只放服务端环境变量（`.env.local`，不进仓库）；语音合成也在服务端做，密钥不进浏览器；页面、日志、导出都不显示密钥 |
| 账号密码 | 服务器上只存 scrypt 哈希；命令行工具不收命令行参数里的密码，报错里不带密码；会话密钥至少 32 个字符，不给默认值 |
| 仓库里不留秘密 | 每次提交前跑 `release:check`，扫描密钥、会话密钥、账号记录、内网地址和本地禁词表；端到端测试用的公开测试账号和测试密钥，线上一律不认 |
| 本轮口令 | 单独存 `secret.json`（3.3 节）；运行清单只放加盐的指纹：随机部分只有 6 位十六进制，不加盐从指纹穷举很快就能还原 |
| 用户的声音 | 体检不收录音；闯关的麦克风用浏览器自带的识别，分寸只收到认出来的文字，不录音、不存音频 |
| 个人信息 | 不收集个人信息；运行记录只存在自己的服务器上；敏感场景只用人工审定的固定输入；试用前提醒不要输入真实个人信息 |
| 被嵌入、被冒用 | 程序自己发不许被别的网站嵌入的响应头；改数据的接口只收本站页面发来的请求 |
| 不被当成真人 | 页头一直有「AI」小印和「回复和声音由 AI 生成」；形象下面写「AI 角色，非真人」 |
