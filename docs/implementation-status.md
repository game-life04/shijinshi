2. 用例全部是草稿：B 改写并审核（填写真实审核人与时间）后才能进入正式统计。
3. 检索目前只有词法 BM25；向量检索与两者对照放在 M3（规格 02 E4）。
4. 测试 Agent 与固定次序、随机次序的对照（E3）尚未实现。
5. 语音输出端已在模拟发声下打通；真实合成 10-27 已跑通；语音输入没做，语音用例仍记「未执行」；E2 成对实验没做。
7. VRM 已接入并验证；11-03 模型压到 7.8 MB（ADR-023）；帧率还要在评审常见的核显笔记本上实测。
8. 首声等待（10-27 已拆解并优化，ADR-020）：开发模式下的 3918 ms 大部分是开发模式开销。生产构建、上游正常时各轮 0.6～1.0 秒；上游变慢时多在 1.2～2.9 秒，偶尔更长。剩下的：模型 11-03 已从 19.3 MB 压到 7.8 MB，加载期间第一轮会不会多等要重新量；正式数据要等 E 系列实验。
6. 体检单导出 PDF 用浏览器打印（11-03）；版式要在评审常用的 A4 打印预览里再看一遍。
